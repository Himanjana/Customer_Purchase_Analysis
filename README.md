Customer Purchase Behavior Study
Overview

An end-to-end analysis of customer purchase behavior to identify trends in sales, revenue, customer demographics, subscription patterns and product categories.

The workflow covers data preparation in Python, SQL-based analysis, interactive visualization in Power BI and presentation of key findings through a report and presentation.

Dataset

The dataset contains customer and purchase-related information, including:

1. Customer demographics
2. Purchase amount
3. Product categories
4. Subscription status
5. Review ratings
6. Shipping type
7. Purchase details
   
Tools
1. Python— Data loading, cleaning and Exploratory Data Analysis (EDA)
2. Pandas— Data manipulation and visualization
3. SQL Server— Data querying and analysis
4. Power BI— Interactive dashboard
5. Gamma— Presentation
6. Microsoft Excel— Data inspection and supporting analysis
   
Steps
1. Data Loading & EDA:
1) Loaded the dataset using Python.
2) Examined data types, missing values, duplicates, and distributions.
3) Performed exploratory analysis to identify trends and patterns.
2. Data Cleaning:
1) Handled missing and inconsistent values.
2) Removed duplicate records where required.
3) Standardized data formats and prepared the dataset for analysis.
3. SQL Analysis
1) Imported the cleaned dataset into SQL Server.
2) Used SQL queries to analyze customer behavior, sales, revenue, categories, demographics, and subscriptions.
4. Power BI Dashboard

Created an interactive dashboard covering:

1. Number of Customers
2. Average Purchase Amount
3. Average Review Rating
4. Customer Distribution by Subscription Status
5. Revenue and Sales by Category
6. Revenue and Sales by Age Group
7. Subscription Status by Gender
8. Category and Shipping Type analysis
   
5. Reporting & Presentation
Summarized key findings and insights in a report.
Created a presentation using Gamma to communicate the analysis and results.
Dashboard

The Power BI dashboard provides an interactive view of customer purchasing patterns, sales performance, revenue distribution, demographics, and subscription behavior.

Results

The analysis helps identify:

1. Customer purchasing patterns
2. Top-performing product categories
3. Revenue and sales trends across age groups
4. Differences in behavior based on subscription status
5. Customer distribution across demographics
6. Relationship between shipping types and purchases

How to Run
1. Clone or download this repository.
2. Open the Python notebooks/scripts and install the required libraries.
3. Load the dataset and run the data preparation and EDA steps.
4. Import the cleaned data into SQL Server and execute the provided SQL queries.
5. Open the Power BI file (.pbix) to explore the dashboard.
